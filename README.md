# pairwise-lockstep-sim

十人联机打到第三关开始漂移，回放里同一颗手雷炸在不同位置，掉线重连后角色站在墙里：固定 tick 累加器用浮点时间，长时间运行后 tick 数和真实时间偏出半帧；输入延迟按本地帧号缓冲，不同客户端帧率下同一输入落在不同 tick；每帧校验和只算角色位置，物理接触点和随机状态没进校验；随机种子由主机时间生成，各端初始种子不同；浮点和三角函数在不同平台结果不一致，物理迭代次数按帧时间动态调整；实体遍历顺序依赖哈希表，增删实体后顺序变化；丢包时直接跳过缺失输入，客户端各自补不同方向；重连同步只发世界快照，不回放缺失 tick，角色被塞进墙里；锁步缓冲在慢客户端上无限增长，快客户端被迫等待；时间膨胀系数按本地帧率算，设备越慢游戏越慢；回放录制只存输入不存校验，复盘时找不到第一次分叉；排序键用对象地址，同一帧内事件顺序不确定；服务器和客户端用不同物理步长，爆炸冲击波范围不同。gameplay/lockstep_sim.py 是核心，tests/test_lockstep_sim.py 15个红。要修的是：整数 tick；输入帧号；全量校验；统一种子；定点物理；实体顺序；丢包补齐；重连回放；缓冲上限；统一膨胀；回放校验；稳定排序；统一步长。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
